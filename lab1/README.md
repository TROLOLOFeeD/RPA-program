**Цель работы**: *Освоить основы автоматизации браузерных операций на примере тестирования функционала интернет-магазина. Получить практические навыки работы с Selenium WebDriver, обработки динамических элементов и параметризации тестов.
**Задача**:*
*Необходимо разработать программного робота (скрипт) на языке Python, который автоматизирует процесс поиска товара и добавления его в корзину на демо-сайте интернет-магазина https://www.saucedemo.com/*

**Параметр 1: Браузер для автоматизации**
*Microsoft Edge*
**Параметр 2: Креденшиалы пользователя (логин/пароль)**
*Г: performance_glitch_user / secret_sauce*
**Параметр 3: Критерий сортировки товаров в каталоге**
*Сортировка по имени (Z to A)*
**Параметр 4: Выбор товара для добавления в корзину**
*Добавить первый товар из списка.*
**Параметр 5: Действие с корзиной**
*Добавить товар в корзину, перейти в корзину и продолжить покупки (вернуться в каталог).*
-----------------------------------------------------------------------------------------------------
**Задание:**
Инициализируйте WebDriver в соответствии с выбранным Параметром 1.

Напишите сценарий, который выполняет следующие шаги:
  Переходит на сайт https://www.saucedemo.com/.
  Находит поля для ввода логина и пароля, вводит данные в соответствии с Параметром 2.
  Находит и нажимает кнопку Login. (Обработайте возможную ошибку, если выбран аккаунт locked_out_user и совершите авторизацию под любым другим пользователем)
  Находит элемент управления для сортировки товаров (dropdown) и выбирает вариант, соответствующий Параметру 3.
  Находит все карточки товаров на странице.
  В соответствии с Параметром 4 выбирает нужный товар и добавляет его в корзину (нажимает кнопку Add to cart).
  Выполняет действие с корзиной в соответствии с Параметром 5.
