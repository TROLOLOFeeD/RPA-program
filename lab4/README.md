# Лабораторная работа №4  
**Работа с реляционной базой данных через программного робота**

---

## Цель  
Освоить технологии подключения, извлечения, обработки и записи данных в реляционную базу данных с помощью программного робота на языке Python.

---

## Задачи  
Робот должен выполнить следующие действия:

1. **Подключиться** к локальной базе данных SQLite (`company_data.db`).
2. **Считать данные** из исходной таблицы `Projects`.
3. **Обработать данные** согласно заданной бизнес-логике.
4. **Записать результаты** обработки в целевую таблицу `project_finance_status`.  
   → Если целевая таблица отсутствует — создать её автоматически.

---

## Исходные данные  

- База данных: `company_data.db` (создаётся отдельным Python-скриптом).
- Таблица: `Projects`  
  Столбцы:
  - `project_id` — уникальный идентификатор проекта  
  - `project_name` — название проекта  
  - `manager` — ответственный менеджер  
  - `budget` — утверждённый бюджет (в рублях)  
  - `spent` — фактически потраченные средства  
  - `deadline` — дата завершения проекта  

> Данные генерируются программно с использованием синтетических (ИИ-подобных) значений.  
> Объём: **не менее 100 записей**.
