***Лабораторная работа 3***


**Цель работы**: 
Освоить принципы автоматизации взаимодействия с почтовыми службами через API и SMTP/IMAP протоколы. Научиться создавать программных роботов для отправки, получения и обработки электронных писем.
**Задача**:
Необходимо разработать программного робота (скрипт) на языке Python, который автоматизирует процесс работы с электронной почтой: отправку писем, анализ входящих сообщений и автоматическое реагирование на них.

**Набор параметров**: 

**Параметр 1: Почтовый сервис**
*Mail.ru (через SMTP/IMAP)*

**Параметр 2: Тип отправляемого сообщения**
*Письмо с вложением и HTML-форматированием*

**Параметр 3: Источник данных для отправки**
*Чтение данных из CSV-файла*

**Параметр 4: Обработка входящей почты**
*Вариант A: Поиск писем с определенной темой*

**Параметр 5: Действие с найденными письмами**
*Скачать вложения в указанную папку*

Набор библиотек: smtplib email imaplib python-dotenv. Для работы с Microsoft Graph API: pip install msal requests
