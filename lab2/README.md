***Лабораторная работа 2***

**Цель работы**: Освоить принципы автоматизации работы с популярными офисными форматами (Excel, Word, PDF) на Python. Научиться создавать, читать, редактировать и форматировать документы с помощью программных роботов, исключая ручной труд.
**Задача**:
Необходимо разработать программного робота (скрипт) на языке Python, который автоматизирует процесс создания отчета на основе исходных данных. Отчет должен быть представлен в трех форматах: электронная таблица (Excel), текстовый документ (Word) и документ для печати/распространения (PDF).

***Набор параметров***:

**Параметр 1: Источник данных**
*Ввести данные вручную через консоль (минимум 5 строк).*

**Параметр 2: Операция с данными в Excel**
*Отсортировать таблицу по убыванию значения в колонке "Цена".*

**Параметр 3: Структура Word-отчета**
*Создать документ с заголовком, маркированным списком основных позиций и итоговой суммой.*

**Параметр 4: Действие с PDF**
*Конвертировать готовый Word-документ в PDF.*

**Параметр 5: Финализация работы**
*Закрыть все открытые приложения (если использовались) и вывести в консоль путь к созданным файлам.*
